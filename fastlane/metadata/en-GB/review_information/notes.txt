Arcfin is a client app for Jellyfin, a free/open-source self-hosted media server (jellyfin.org) — it has no content or account system of its own, so a server is required to sign in and evaluate playback.

Suggested path to test:
1. Launch Arcfin.
2. On the "Add Server" screen, enter a reachable Jellyfin server URL.
3. Sign in with a Jellyfin account on that server.

For review, the official public Jellyfin demo server can be used:
  Server URL: https://demo.jellyfin.org/stable
  Username: demo
  Password: (none — leave the password field in Arcfin's sign-in screen empty and tap Sign In)

The demo account genuinely has no password set. Arcfin's sign-in screen only requires a
username to enable the Sign In button — the password field is optional, matching Jellyfin
itself, which allows accounts configured with no password (common for demo/kid profiles).
If the button still looks disabled, that's a stale build; this build fixes it.

NOTE TO SELF BEFORE SUBMITTING: verify the demo server is online and the "demo" account
still exists/still has no password — this was not confirmed live immediately before
submission and demo server uptime/config can change without notice. If it's down or no
longer passwordless, submit a private Jellyfin server + test account of your own instead,
since Apple's reviewer needs *something* that works to actually evaluate the app.

Once signed in, the reviewer can browse the library, play a video (direct play or
transcoded depending on the source), and try Settings > Playback, Downloads, and the
profile picker (Face ID/PIN lock is off by default — it's an opt-in per-profile setting
under Settings, not required to use the app).

Local network permission (server/Chromecast discovery) and location permission (home
Wi-Fi network name, used only to switch between a server's local/remote address) are both
optional — declining either still leaves the app fully usable by entering a server URL
manually.
